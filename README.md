# AI Mini Projects

머신러닝과 딥러닝 실습을 위한 미니 프로젝트 모음입니다.

## 프로젝트

- `mini-project-01/`
  - 공유자전거 대여 수요 예측 — 회귀
  - 온라인 쇼핑 구매 여부 예측 — 분류
- `mini-project-02/`
  - CV 객체 탐지 — YOLO
  - NLP 감정 분석 — BERT

## 실행 환경

Python 3.11과 `uv`를 사용합니다.

```powershell
uv sync
```

VS Code에서 프로젝트의 `.venv` Python 커널을 선택한 뒤 Notebook을 순서대로 실행합니다.
